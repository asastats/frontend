{% comment %} Tailwind/DaisyUI base template, standing beside base.html during the migration. A page belongs to exactly ONE of the two: Materialize and the DaisyUI build both define .btn, .card, .card-title, .modal, .badge, .container, .avatar, .input, .truncate, .disabled and .fixed, so a page that loaded both would have whichever lost the cascade silently deform. The block names are deliberately identical to base.html's, so converting a page is a one-line `extends` change plus the markup inside those blocks. When the last page moves off base.html, this file becomes base.html. {% endcomment %} {% load static %}{% load i18n %} {% comment %} Stamp the saved theme before the stylesheet paints, so there is no flash of the default one. Three changes worth knowing about: * the primary nav marks the section you are in with `aria-current="page"`, the same contract the auth tabs and the profile sub-nav use. Without it a reader had no way to tell where they were except by reading the url; * account actions are separated from navigation.
