The structure is a contract with address.js: * `.asasec` is the container it reopens a remembered entry inside; * each entry is `id="f"` with class `fitem` -- the filter shows and hides these, and `checkOpened` matches on the id; * `.token.item-header` is the summary it binds `showExpiry` to; * `.item-body` is what `showTimes`/`showExpiry` search for epoch spans; * `.val` carries the unvarnished value in `data-val`, which is what the ALGO/USD switch recomputes from -- the visible text is rounded and is not a safe source; * `.unit` is rewritten in place when the currency switches. Change the nesting or these names and the page still renders perfectly while filtering, sorting and the currency switch quietly stop working. {% endcomment %}
