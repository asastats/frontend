{% comment %} The pin control on an asset or collection row. Pinning is remembered per address/bundle in the reader's own browser and never reaches the server -- see `static/js/pins.js`. That is not a shortcut: this page's cache entry is shared between signed-in readers, so anything per-reader rendered into it would be handed to whoever asked next. Rendering the button in the *unpressed* state for everybody and letting the script press it is what keeps the markup shareable. `data-pin` is the id of the entry this pins -- the same id `checkOpened` and the filter use, so a pin survives everything else that addresses the row. Required context: pin_id the entry's id *without* the `f` prefix (an asset id, or a slugified collection name) pin_label what to name in the accessible label, e.g. the unit or the collection name {% endcomment %}
