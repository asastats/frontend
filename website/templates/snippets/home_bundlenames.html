The structure is a contract with `home.js`: * each row is a **direct div child** of `.bundlenames` -- the sorter does `$(".bundlenames").html($(this).children("div").sort(...))`, so a wrapper here would leave it sorting one element; * the row keeps `.cardiv`, which the filter shows and hides; * `data-name` / `-addresses` / `-created` / `-modified` / `-size` are the sort keys *and* what the filter matches on.
