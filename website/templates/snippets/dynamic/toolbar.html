{% comment %} The dynamic toolbar for designs 2 and 3. Everything here acts on the page already in the browser: the sort keys and categories are rendered onto the rows as data attributes (see `snippets/dynamic/asset.html` and `position.html`), so nothing fetches. **Every control ships in its default state**, and `toolbar.js` applies the reader's own on load. This page's cache entry is shared by everyone on the layout, so a control rendered pressed would be handed to whoever asked next. The counts beside the sort buttons are filled in for the same reason. `aria-pressed` on every segmented button, because these are toggles rather than links. {% endcomment %}
