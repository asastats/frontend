{% comment %} One grid of theme swatches. Included once per scheme, so the Dark and Light tabs cannot drift apart in markup -- they are the same control over a different list. Takes `themes`, a list of theme names. `data-theme` on the label makes each swatch render in the theme it offers, so the preview is the real thing rather than an approximation maintained by hand. Selection is the same mechanism as the header dropdown: a radio named `theme-dropdown`, wired by static/js/theme.js. Reusing the name means this page needs no script of its own, and the two controls cannot disagree about what is selected. {% endcomment %}
