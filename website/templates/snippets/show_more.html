{% comment %} Reveals the rows the load-more rule folded away. Context: hidden (how many rows the next press reveals), noun (what they are, plural). The rows are already in the document, marked `.folded`; this fetches nothing. The control names how many and what, because eight more assets and two hundred more are different decisions. **`hidden` is what the next press reveals, not the whole tail.** A control saying "Show 39 more assets" that reveals twenty has told the reader something untrue about itself. Both labels are rendered and the stylesheet shows one, keyed off `aria-expanded`, so the state lives in the attribute a screen reader already reads rather than in text a script has to keep in step. The scripts rewrite the count inside `.show-more-open` and read the noun off `data-noun` - the alternative is a plural hardcoded in two JavaScript files, which is how "1 more collections" gets shipped. {% endcomment %}
